📑 Format Template Import

File Excel berisi daftar calon peserta. Kolom No. Registrasi tidak diperlukan. Nomor registrasi akan dibuat berurutan berdasarkan kedatangan di resepsionis.

💡 Tips: Jangan mengubah nama/header kolom. Satu baris = satu peserta. Jika file dibuka tanpa internet, gunakan Template CSV; CSV dapat diimport tanpa modul Excel.
